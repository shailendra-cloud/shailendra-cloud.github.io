# shailendra-cloud.github.io

Personal academic website of Dr. Shailendra Tiwari, served by GitHub Pages at
https://shailendra-cloud.github.io/

## Updating the site

Everything lives in `index.html`. Edit a file on GitHub, commit, and the site
updates about a minute later.

| What | How |
|---|---|
| Photo | Upload a portrait as `assets/photo.jpg` (portrait orientation, about 600 × 720 px). Until then a monogram is shown. |
| CV | Upload `cv.pdf` to the repository root. The "CV (PDF)" buttons appear on their own. |
| News | In `index.html`, search for `NEWS`. Newest first; items with `class="more"` stay behind "Show all". |
| Publications | Search for `PUBLICATIONS` (the `PUBS` list near the bottom). Fields: `y` year, `t` type (`journal`, `conf` or `chapter`), `title`, `a` authors, `v` venue, and optional `d` details, `doi`, `url`, `code`, `st` status such as `'Accepted'`. |
| Citation numbers | Search for `STATS` in `index.html`. |

The live CT reconstruction band under the header is computed in the browser;
it needs no files.
